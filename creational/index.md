# Creational Patterns

Creational patterns provide various object creation mechanisms, which increase flexibility and reuse of existing code.

| # | Name | Description |
|:-:|------|-------------|
| 01 | [Builder](./builder/) | Construction of complex or multi-representational objects |
| 02 | [Singleton](./singleton/) | Only one existing instance of a class |
| 03 | [Prototype](./prototype/) | Create new objects by copying an existing object |
